# Wiki Proposals

本目录保存 Codex 或其他本地 AI 生成、但尚未进入正式 Wiki 的 Markdown 修改提案。
预测运行不得读取或引用这里的内容。

每个提案应说明：

- 目标 Wiki 稳定 ID 与当前版本；
- 建议的新版本和变更等级；
- 触发来源、原始 URL、发布时间、抓取时间和内容哈希；
- 新结论、被替代结论、矛盾与未解决问题；
- 对历史预测无回写、对未来预测何时生效；
- lint、链接、时间与引用校验结果。

提案通过审查后，修改正式条目、更新 `wiki/index.md`，并在 `wiki/log.md` 追加 promote
记录。不要把提案文件本身改名冒充正式条目。
