# Lesson archive layout

This directory documents the public archive format only. Rendered Lesson
candidates default to the Git-ignored `data/lesson-archives/` directory.

A candidate never changes prediction weights or historical conclusions
automatically. Its replay evidence, review state, activation, challenge,
retirement, and any later Wiki promotion remain separate governed steps.

`reflection-finalize` does not write Markdown. The separate
`reflection-render` command creates immutable local Lesson archives after a
completed Live reflection; draft-producing Agents cannot edit them directly.
