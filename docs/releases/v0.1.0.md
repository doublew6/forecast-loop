# forecast-loop v0.1.0

This is the first public-core release of forecast-loop.

Highlights:

- deterministic validation and immutable forecast/evidence records;
- source-neutral read-only provider and adapter contracts;
- human, model, quantitative, and deterministic signal inputs;
- portable audit bundles, reproducible builds, and release provenance;
- local demo mode with no model key required.

See `CHANGELOG.md` for the complete public change history and
`docs/upgrading-to-v0.1.md` for compatibility notes.
